The starport is a fictional logistics application demonstrating the cccteam resource stack end to end: generated handlers and routes, field-level permission enforcement, and a config-driven frontend.

Operations Manage Ships, Docking Bays, and Crew Members. Ship detail pages can execute the Authorize Launch RPC. Logistics Browse Cargo Manifests (composite primary key) and Supply Crates (server-populated, input-only, and output-only fields, with change tracking). Stations Berths and Authorize Docking are station scoped: permissions are partitioned per station, so the demo user is authorized in station-alpha but not station-beta.
